## 目标

把 MewCode 界面按截图样式重做成黑底+橙色强调的 Textual 全屏工作台：欢迎面板（品牌/模型/目录、Tips、Recent activity）、中间对话工作区、底部 `>` 输入区、底部状态栏。工具调用卡片（`⎿ ⎿` + spinner + `✓/✗`）渲染在主工作区。保留现有 Terminal CLI 模式（`app.py`）作为备用运行路径，测试继续覆盖。

## 改动清单

### 1. `pyproject.toml` — 加回依赖
- `dependencies` 添加 `textual>=0.50.0`

### 2. 新增 `src/mewcode/tui.py` — Textual 工作台
**主题**（全部 CSS 内联，不引入外部主题文件）：
- 背景纯黑 `#0a0a0a`，主色橙 `#e8862d`（边框/标题/工具卡），正文浅灰 `#e8e8e8`，次要 `#8a8a8a`，成功 `#7cc97c`、失败 `#e07070`

**布局**（compose）：
- 欢迎面板（首次进入 / 新会话时可见，横向两栏）
  - 左栏：大标题 `MewCode v0.x`（橙）、模型、当前工作目录、版本号
  - 右栏：`Tips for getting started`（/new /sessions /use <id> /clear /exit、直接提问开始对话）、`Recent activity`（storage 最近会话：id + 更新时间 + 模型，无历史显示提示）
- 对话区：`RichLog(id="conversation")` — 用户消息、流式回答、工具卡片
- 工具执行区：`Static(id="tool-status")` — 执行中显示 spinner 动画（`⠋⠙⠹…` + 当前工具名）
- 输入区：`Static("> ")` + `Input`（水平排列）
- 状态栏：`Static(id="status")` — 左侧 `ctrl+c 退出 · 模型 xxx · 会话 id`，右侧 `● 已连接 / 生成中`

**交互**：
- 启动：会话有历史 → 直接进入对话工作区并渲染历史（含 tool_use/tool_result 块）；无历史 → 显示欢迎面板
- 首次输入 → 隐藏欢迎面板、进入对话区
- 流式回答实时写入对话区
- 工具调用：对话区先写 `⎿ ⎿ 工具名 参数摘要` 行 + tool-status 区 spinner 动画；完成后在同区写 `✓ ⎿ ⎿ …（耗时）` / `✗ …（原因）` 行，spinner 停止；结果回传模型
- 命令处理复刻现有 `_handle_command` 逻辑（/new /sessions /use /clear /exit），/new 后重新显示欢迎面板
- 编排逻辑 `_stream_turn` / `_execute_tools` / `_finish_turn` 与 `app.py` 现有一致（碎片按 index 拼接、单步工具调用、多轮提示），仅渲染改为 Textual 控件

### 3. `src/mewcode/__main__.py` — 入口切回工作台
- 装配 `ToolRegistry` + `OpenAICompatibleClient(tools=registry.api_specs())` + `MewCodeTUI(config, storage, client, registry).run()`

### 4. `src/mewcode/app.py` / `terminal.py` — 不动
- Terminal CLI 保留为备用/测试路径，e2e 测试继续使用，降低回归风险

### 5. 测试 — 重写 `tests/test_tui.py`
- 欢迎面板：启动无历史时出现品牌/Tips/Recent activity，输入一条消息后切换到对话工作区
- 对话渲染：输入问题 → 流式文本出现在对话区；消息持久化
- 工具调用：mock client 第一轮返回分片 ReadFile 工具请求 → 对话区出现 `⎿ ⎿ ReadFile` 与 `✓` 完成行，会话含 tool_use/tool_result 块可恢复
- 命令：/new 切新会话并回到欢迎面板、/clear 清空、/exit 退出
- `/sessions` 展示 Recent activity 内容
